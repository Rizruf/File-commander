**File Commander** — это легковесный консольный файловый менеджер, разработанный для демонстрации принципов **Clean Architecture** и глубокого понимания работы с файловой системой (System.IO) в .NET.

Проект построен вокруг паттерна проектирования **Command**, что обеспечивает высокую расширяемость и соблюдение принципов SOLID (в частности, Open/Closed Principle).

---

## Основной функционал

Приложение реализует базовый набор операций для управления файловой системой через интерфейс командной строки (CLI):

* **Навигация:** Просмотр содержимого директорий и перемещение по папкам.
* **Манипуляция файлами:** Копирование, создание и удаление файлов.
* **Рекурсивные операции:** Поддержка копирования и удаления целых директорий с вложенным контентом.
* **Безопасность:** Встроенная защита от случайного удаления (подтверждение действий) и обработка исключений доступа (try-catch).
* **Информативность:** Получение метаданных о файлах (размер, дата создания).

## Архитектура и Технический стек

Проект написан на **C# 12** (.NET 9.0) без использования сторонних библиотек.

### Ключевые архитектурные решения:

1.  **Command Pattern:** Вся логика инкапсулирована в отдельные классы команд (`CopyCommand`, `DeleteCommand` и др.), реализующие единый интерфейс `ICommand`.
2.  **Invoker (CommandManager):** Центральный хаб, который регистрирует команды, парсит ввод пользователя и вызывает соответствующую бизнес-логику.
3.  **Dependancy Injection (Lite):** Команды внедряются в менеджер через конструктор, что позволяет легко добавлять новый функционал без изменения существующего кода.

## Список команд

| Команда | Алиас |                      Описание                         |   Пример использования   |
|---------|-------|-------------------------------------------------------|--------------------------|
| `ls`    | `dir` | Вывод содержимого текущей директории (файлы и папки). | `ls`                     |
| `cd`    |   -   | Смена текущей рабочей директории.                     | `cd C:\Projects`         |
| `cp`    |   -   | Копирование файла или папки (рекурсивно).             | `cp data.txt backup.txt` |
| `rm`    | `del` | Удаление файла или папки (с подтверждением).          | `rm old_folder`          | 
| `touch` |   -   | Создание ресурса. Флаг `-f` для файла, `-d` для папки.| `touch -f logs.txt`      |
| `info`  |   -   | Вывод метаданных файла (размер, даты).                | `info photo.png`         |
| `help`  |   -   | Вывод списка доступных команд.                        | `help`                   |

## Установка и запуск

**Требования:** .NET SDK 8.0 или 9.0.

1.  Клонировать репозиторий:
    ```bash
    git clone [https://github.com/Rizruf/File-commander.git](https://github.com/Rizruf/File-commander.git)
    ```

2.  Перейти в папку проекта:
    ```bash
    cd File-commander
    ```

3.  Запустить приложение:
    ```bash
    dotnet run --project File-Commander
    ```
